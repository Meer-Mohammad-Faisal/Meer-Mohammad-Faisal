## 💳 PayFlowX — Payments & Ledger System

> Backend-focused payment and ledger platform designed around financial correctness, idempotency, reconciliation, and asynchronous processing.

**Tech Stack:** Node.js • TypeScript • Fastify • PostgreSQL • Redis • BullMQ • Razorpay • React • Docker • AWS

### Highlights

- 💰 Designed an **immutable double-entry ledger** using PostgreSQL.
- ⚖️ Enforced the **debit = credit invariant** through ACID transactions.
- 🔄 Built a **6-state payment state machine**:

```text
CREATED → PENDING → AUTHORIZED → CAPTURED → SETTLED → REVERSED
```

- 🔐 Implemented **idempotency keys** to prevent duplicate payment processing.
- 🧾 Built **automated reconciliation workflows** to detect and resolve ledger mismatches.
- ⚡ Used **BullMQ + Redis** for asynchronous payment processing and webhook handling.
- 🔗 Integrated **Razorpay** payment gateway with webhook verification.
- 🐳 Containerized with Docker and deployed on **AWS EC2**.
- 📊 Built a React dashboard for transaction monitoring and ledger inspection.
